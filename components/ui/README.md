# components/ui

Generated by **shadcn/ui** (style `base-nova`, built on **Base UI** `@base-ui/react`).
The code is ours to edit; there is no shadcn package to update. To add a component:

```bash
npx shadcn@latest add <name>
```

Base UI uses a `render` prop where Radix-based shadcn used `asChild`, e.g.
`<DropdownMenuTrigger render={<SidebarMenuButton />}>`. Vendor notes: `docs/VENDORS.md`.
